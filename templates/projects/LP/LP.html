Linear programming is a method to achieve the best outcome (maximum/minimum) in a mathematical model. The objective function is to optimize a linear function, subject to non-negative, linear equality and inequality constraints.

Key terms:

  1. Decision variables: variables that decision-makers control to optimize the objective function
  2. Objective function: The mathematical expression representing the quantity to be maximized or minimized
  3. Constraints: The restrictions/limitations on the decision variables. Constraints can be represented as linear inequalities or equalities
  4. Feasible region: the set of all possible solutions that satisfy the constraints
  5. Optimal solution: the solution that maximizes or minimizes the objective function within the feasible region

Linear Algebra Review

Let Ax = b, where A is an m × n matrix. Rank of a matrix is the number of linearly independent rows.

Inconsistent: If the left-hand side of the equation is the same, but the right-hand side is different, then it is impossible to solve and no solution exists.

Case 1: m = n (Square Matrix)

  • If rank(A) = n: unique solution
  • If rank(A) < n:
    • infinitely many solutions if consistent
    • no solution if inconsistent

Case 2: m < n (Underdetermined)

More variables than equations.

  • If rank(A) = m and is consistent: infinitely many solutions
  • If inconsistent: no solution

Case 3: m > n (Overdetermined)

More equations than variables.

  • If rank(A) = n and the system is consistent: unique solution
  • If rank(A) < n and the system is consistent: infinitely many solutions
  • If inconsistent: no solution

Relation to linear programming

When we have Ax = b, the solution is the intersection point of the lines. Imagine two system of equations. Each equation represents a line. The solution is the intersection point of the lines.

  • If there is an intersection, we have a unique solution.
  • If it's the same line, then there are infinitely many solutions
  • If there are parallel lines, then it is inconsistent (no solution)

Optimization problems usually involve limits/requirements. In optimization, the matrix A, represents each resources/activity used, x are the decision variables, and b are the limits. We have Ax ≤ b to represent the limits. The inequalities define a feasible region which contains all possible solutions satisfying the constraints and the objective function is then optimized over the feasible region. Even though linear programming uses inequalities, the concepts from linear algebra such as systems of equations, rank, consistency and intersections are still fundamental to undestanding optimization problems.
